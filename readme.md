# AI Resume Screening System

An end-to-end Machine Learning and NLP-based web application that analyzes resumes against job descriptions and provides a match score, skill gap analysis, and candidate shortlisting.

## 🚀 Features
- Resume parsing from PDF
- Job description matching using TF-IDF & cosine similarity
- Automated skill extraction
- Resume match percentage
- Candidate shortlisting decision
- Interactive Streamlit dashboard with visualizations

## 🛠 Tech Stack
- Python
- Machine Learning
- NLP
- Scikit-learn
- Streamlit
- Matplotlib

pip install -r requirements.txt
